# Karmika — Cooperative Gig Services Platform

A cooperative-owned digital marketplace connecting skilled workers — electricians, plumbers, carpenters, painters, domestic helpers, caregivers, and more — from Labour Cooperative Societies with households and communities that need their services.

Built for **Smart India Hackathon 2026**, under the Ministry of Cooperation (National Council for Cooperative Training).

## 🚧 Currently in Development

This project is actively being built. Features are being added incrementally, and things may be incomplete or changing frequently.

### What's working so far
- User signup & login for Customers, Workers, and Admins
- Browsing and booking household services
- Location-based matching of nearby available workers
- Live booking status tracking
- Multilingual interface (English & Hindi, more coming)

### Coming up
- Cooperative Federation admin dashboard
- AI-based demand forecasting
- Worker welfare & insurance integration
- Payments integration

*This is a prototype under active development — not yet a production-ready platform.*
